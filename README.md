## About DooDay

DooDay is designed to make bowel movement tracking simple and easy.

With DooDay you can:

- Log a bowel movement with one tap
- See when you last went
- View your poop history on a calendar
- Track multiple bowel movements in one day
- Add or remove previous entries
- Set a reminder if you haven't logged a bowel movement after a certain number of days
